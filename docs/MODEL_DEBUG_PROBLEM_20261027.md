# 20自由度主轴动力学：待分析问题与复现材料

本文描述已观测到的现象，供独立检查模型方程、数值过程和稳态判据。当前没有确定的根因，也没有证据证明所有差异都是求解器发散或模型错误。本文使用的路径以压缩包根目录为准：源码在 `project/`，运行证据在 `evidence/`。

## 1. 要解决的问题

固定同一组20自由度参数，让四只外圈与机壳之间的径向配合间隙同步从1增至10 μm，25个间隙分别冷启动。在每点均导出完整结果且通过小转角筛查的情况下，**14点通过运行内稳态检查，11点未通过**。主要问题是：

1. 3.25 μm附近，带内振动、阶次及部分接触力在不同时间子窗间变化，h/2或N加密后的部分指标也与基准超出比较门限。
2. 10 μm点的完整记录和不同数值设置的总体指标很接近，但若干较弱相干阶次在子窗之间超限，即使记录加长到960转仍未通过。
3. 需要判断这些现象分别可能来自有限窗口、尚未消失的暂态、非周期/拍频或分支、接触模型与阻尼实现、数值误差，还是其他因素。**以上只是待检验的方向，不是预先认定的原因。**

运行内 `NOT_STEADY` 是本次多指标、多子窗判据的结果；它本身不等于ODE发散。两条未稳态轨迹之间的差异也不能单独解释成步长或周向离散不收敛。反过来，个别指标或完整窗口的跨运行差值通过，也不能覆盖子窗不稳态。

机械仿真产生在β增益、M1合成和TCN之前，因此这些下游处理不是这里观测到的动力学差异的成因；不需要用下游网络或合成信号解释本问题。

## 2. 20自由度模型及固定输入

### 坐标、受力和简化

20个广义坐标依次为：

```text
q = [Sx, Sy, Tx, Ty, Hx, Hy, O1x, O1y, θx, θy,
     O2x, O2y, OR1x, OR1y, OR2x, OR2y, Cx, Cy, Px, Py]
状态 y = [q, dq/dt]，共40维。
```

S为转子参考截面，T为刀柄侧质量，H为机壳，O1/O2和OR1/OR2分别是前、后四只轴承外圈的径向XY位移，C、P为安装链中间件及平台，G为地。θx/θy为转子小转角。模型的基本形式是 `M q¨ + R(t,q,q˙) = F_gravity + F_unbalance(t)`；陀螺项使用带符号转速并进入左端速度项。沿轴向z的转子截面位移及径向力的广义力为：

```text
u_x(z) = Sx + z·θy         u_y(z) = Sy − z·θx
[F_Sx, F_Sy, M_θx, M_θy] = [Fx, Fy, −z·Fy, z·Fx]
```

T通过转子 `z_T=0.165 m` 截面与转子相连；F1/F2/R1/R2的滚动接触内圈侧作用在转子各自截面，外圈侧分别作用于O1/O2/OR1/OR2。四只外圈通过各自单边配合与H相连。H、C、P、G构成 `H–C–P–G` 弹簧阻尼安装链；原基础模型的H–地支承在安装适配中被移除，不应与安装链重复计算。`src/spindle/installation_dynamics.py` 的 `internal_force` 与 `src/spindle/installation_fast_rhs.py` 的 `append_installation` 分别是参考实现和快速后端的相应路径。

四只轴承的载荷位置和定向号依次为 F1 `(z=0.120 m, s=-1)`、F2 `(0.090 m, +1)`、R1 `(-0.127 m, +1)`、R2 `(-0.113 m, -1)`。采用DB/DB布置的条件性假设；内圈与外圈的相对位移和转子相对倾角共同计算单球压缩，正常向力和局部接触力矩都回到转子方程。每只轴承的外圈只平动，轴向位移和外圈倾转不作为自由度。

与源码一致的单球接触概念式如下；`v_n` 是代码对相对速度和角速度的投影，具体实现以 `bearing_wrench` 为准：

```text
δ_i = δ0 + cos(α)(u_x cosφ_i + u_y sinφ_i)
      + s ρ sin(α)(θx sinφ_i − θy cosφ_i)
Q_i = 0                                  若 δ_i ≤ 0
    = max(0, Keq·δ_i^(3/2) + c_ball·v_n) 若 δ_i > 0
φ_i(t) = ω_cage·t + cage_phase + 2πi/球数
ω_cage = Ω/2 · (1 − d_ball/D_pitch·cosα)
```

四只外圈配合均为离散方向的单边径向接触，`n_i=[cos(2πi/N), sin(2πi/N)]`，相对位移r和速度v取对应外圈减H。方向压缩 `d_i=r·n_i−c`，当 `d_i>0` 时的法向量值为 `max(0, (4K/N)d_i+(4D/N)v·n_i)`，否则为零；总力为各方向法向量值乘 `n_i` 的和。几何完全脱开与阻尼裁零导致无承载力分别记录，不能混为一项。`N=512/1024` 指**配合接触方向离散数**，不是滚动体数量。

模型采用固定接触角、等效预紧和条件性刚度/阻尼；没有求解滚动体自身惯性、离心或滚动体陀螺平衡，也没有外圈/安装件转动或轴向自由度。转子的陀螺项仍在模型内。轴承布局、后外圈配合参数和部分几何并非由整机CAD或FRF唯一辨识；代码的通过结果不代表实机几何精度。

16自由度模型仅作为历史结构参考：12机械+4安装自由度，后外圈绑定H；20自由度为16机械+4安装，后两外圈各有独立XY及配合。**零后间隙不等于把外圈刚性绑定H**。两套模型的冻结安装参数不同，不能用其直接对比单独归因于后外圈结构。

## 3. 数值设置、输出和判据

每个主扫描点从各自的静力平衡及零速度启动，不使用相邻间隙动力学终态续接。静力初值使用 `equilibrium_continuation` 的间隙分步求根，最终求解装配后的静平衡；这是静力求根，不是把上一扫描点的动态响应分支续接过来。每个扫描点仅一次正式尝试：冷启动热身3.5 s，然后记录480完整转，前后另各保留0.55 s滤波保护段。25点的 `warmup_history.json` 均记录一次尝试。

| 数值设置 | 值 |
|---|---|
| 积分 | `scipy.solve_ivp` 的 `DOP853`；`rtol=2e-7`；`max_step=1.1260832739219432e-5 s`；各0.125 s区块稠密输出 |
| 绝对容差 | 平动 `1e-12 m`、平动速度 `1e-8 m/s`、角度 `1e-11 rad`、角速度 `1e-7 rad/s` |
| 采样 | 原生65536 Hz；速度经重采样后使用两级各4097抽头的Kaiser FIR（10–2048 Hz及900 Hz低通），输出8192 Hz、10–900 Hz，保留物理幅值；无β缩放 |
| 480转基准窗 | 转速绝对值7000/60转/s，约4.114286 s；代表点正式窗约为3.505215–7.619500 s |
| 输出传感器 | `ACC2=Hx`、`ACC1=Hy`、`ACC3=Py`；20自由度位移/速度状态索引 `[4,5,19]`，按名称解析 |
| 回转误差 | `M−P`：`z=0.165 m`转子截面M减平台P的原生位移，保留1×；`Ex`、`Ey`是各方向逐圈峰峰值的均值，`E_dir=max(Ex,Ey)`。逐圈边界插值、圈内用原生采样极值，不是连续解的解析极值 |

运行内稳态把480完整转分为4个等长120转子窗，逐项检查全部6对组合；960转时为4个240转子窗。比较条件统一为 `|a−b| ≤ max(绝对底限, 相对比例·max(|a|,|b|))`：

| 指标 | 限值 |
|---|---|
| `E_dir`、`Ex`、`Ey` | 2%，底限 `1e-4 μm` |
| 三通道10–900 Hz速度RMS | 2%，底限 `1e-4 mm/s` |
| 1× RMS、联合拟合1–7×相干阶次RMS、拟合残差RMS、非整数带RMS | 5%，底限 `1e-4 mm/s` |
| 四只配合及四只滚动接触的动态力RMS、峰力 | 5%，底限 `1e-4 N` |
| 配合及滚动接触力冲量 | 2%，底限 `1e-7 N·s` |
| 四只配合的几何完全脱开比例 | 绝对差不超过0.02 |

此外，X/Y两方向各子窗M−P静态均值的全范围不得超过 `max(1e-4 μm, 0.02×各子窗最大E_dir)`。动态力RMS按XY分量先减本窗均值；峰力取XY合力模长的最大值；冲量为该模长对时间的积分。不同记录时长的冲量只比较**等长480转区间**。速度带内RMS采用Hann窗能量积分；相干阶次为同时拟合DC及1–7阶的峰值除以√2，非整数带排除1–7阶各±2 Hz。比较代码为 `project/utils/metrics.py` 的 `LIMITS`/`compare_features`；分窗为 `project/src/generation.py` 的 `stationarity`。

`domain_pass` 仅表示本次 `max(norm([θx,θy])) ≤ 0.001 rad` 的小角度筛查通过，并没有验证实际接触压力或高速预紧是否合理。

## 5. 独立复核：1、3.25和10 μm

三个点分别做 h/2、四只配合N从512增至1024、480→960转；h与N未同时改变。输出采样检查从同一数值解比较65536和32768 Hz；健康长记录额外比较同解65536和131072 Hz。对960转比较基准480、长记录首480、长记录末480，冲量始终按等长窗口比较。完整结果及每项的原值、差值、门限在 `evidence/model_audit/gap_<间隙>um/comparisons.json`，各变体的 `stationarity.json` 保留其内部六对结果。

### 1 μm：本点通过

基准和h/2、N1024、960转均STEADY，小角度筛查和所有比较项通过。E_dir基准 `2.176943087 μm`；h/2与基准差 `4.356e-6 μm`，N1024差 `7.058e-6 μm`。健康逐阶不确定度预算 `3×7` 全为工程底限 `1e-4 mm/s`，E_dir预算为 `0.0001150493 μm`；它是各项实际差异与底限取大值的工程估计，不是统计置信区间。证据：`evidence/model_audit/gap_1um/budget.json`。

健康速度RMS为 `[0.0342185242,0.0314629071,0.0406350379] mm/s`，与fit参考之比分别 `[1.20528683,0.94834887,0.70443015]`，与val参考之比分别 `[1.49404274,0.98627439,1.30615056]`，均在 `[0.5,2]`。这里的冻结标定仅使用β前10–900 Hz三通道RMS；**回转误差和1×只报告，不用于拟合或选参门槛**。历史联合标定曾要求E_dir在1.9–2.1 μm，用户已经撤销该门槛，不能用现在的2.176943 μm判定RMS-only标定失败。历史搜索按预算终止，不能称优化已收敛。参考及口径见 `project/config/calibration_targets.json` 和 `evidence/model_audit/health_rms_acceptance.json`。

### 3.25 μm：基准及各细化均未稳态

基准480转四个120转子窗的Hx带内RMS依次为 `0.282344、0.310456、0.313483、0.329807 mm/s`；六对子窗均有未通过项，涉及带内RMS、相干阶次、残差/非整数带、部分接触峰力和脱开率。均值漂移检查通过。小角度筛查通过，并不改变未稳态状态。

- **h/2**：与基准E_dir差 `0.007346 μm`，限值 `0.173168 μm`，该项通过；F1配合峰力差 `11.900 N`，限值 `5.608 N`，未通过。相干阶次、残差、配合和滚动峰力也有超限项。h/2运行自身仍NOT_STEADY。
- **N1024**：E_dir为 `8.633354 μm`，与基准差 `0.017697 μm`、限 `0.173021 μm`；Hx RMS从 `0.326260` 变为 `0.304884 mm/s`，差 `0.021376`、限 `0.006525 mm/s`。带内RMS、相干阶次、残差/非整数带及接触峰力存在超限；N1024运行自身仍NOT_STEADY。
- **960转**：四个240转子窗的六对比较都有超限，涉及RMS、阶次、残差和接触力等；基准480与长记录首480的各项比较通过，基准与末480以及首末480比较均有超限。首末480的Hx RMS为 `0.326260→0.309630 mm/s`，差 `0.016630`、限 `0.006525 mm/s`；E_dir差 `0.021250 μm`、限 `0.173446 μm`。均值漂移仍通过。

这些现象说明所保留记录内不同时间区间差异需要解释；由于原始和细化运行都未稳态，目前既不能认定是ODE发散，也不能把h/N超限直接归因于离散误差。采样对比单独通过，但**本点没有PASS的逐阶误差预算**。

### 10 μm：记录总体差异较小，但弱阶次仍不稳态
