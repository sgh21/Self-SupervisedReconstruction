## 0. 本轮目标、范围与不可更改的约束

本轮**只处理 20 自由度物理仿真及其数值/稳态判定**，不做传递参数重新标定、不计算 β、不生成 M1 合成信号、不训练或验证 TCN。此前健康状态 1 μm / RMS-only 标定等任务暂不执行。

以本项目的 `spindle_model_code_only_20261027.zip` 中 `project/` 为起点，对应 20 自由度模型；先完成经过证据支持的修复和测试，再冻结新版本，以如下工况开展**严格顺序扫描**：

- **前轴承 F1、F2：**二者使用相同间隙，按 1–10 μm、共 25 级，从小到大依次计算。
- **后轴承 R1、R2：**分别保留独立可调接口，但**本次固定为 2.0 μm、2.0 μm**，从第一组到最后一组都不允许跟随前端变化。
- 激励、转速、相位、转子/外圈/壳体质量、轴承本构名义参数、实际安装刚度/阻尼、坐标与测点定义必须保持冻结；除经独立证据确认为计算错误且必须修正的代码外，不得靠改物理参数压低振动或强迫周期性。
- 各工况都按**独立静力平衡 + 零初始速度冷启动**；不得用前一级动态终态续接，也不得逐工况优化输入或阻尼。
- **一旦某一级求解失败、出现非有限值/越界、稳态不达标、数值加密不收敛，或关键判据仍存在未解决的不确定性，应立即停止整个前间隙扫描，不得计算下一等级。** 仍可仅围绕首个失败工况做诊断，不得在报告中把“诊断成功”直接等同于原扫描继续通过。
- **修正后的扫描不要求回转误差或速度 RMS 随间隙单调增加。** 不得通过调大门槛、隐瞒弱谱线、滤掉真实非整阶成分，使全部25级被动变成 PASS。

> **重要解释：**本次 1 μm 是**前组扫描起点**，不是“四只轴承间隙均为 1 μm”的健康配置。第一组实际上是 F1=F2=1 μm、R1=R2=2 μm。旧结果中“四只间隙同步扫描”的 3.25/10 μm 数值，只用于定位旧问题，不得直接作为这次工况的预测或验收标准。

### 2.2 优先修正已验证的阶次观测问题

重点检查：`utils/metrics.py` 的 `design_matrix()` / `fit_joint()` / `signal_features()`，以及 `src/generation.py:103–130` 的 `stationarity()`。

- 采用能抑制强非整数阶泄漏的方案，例如在**相同绝对时间相位和窗口长度**上进行 Hann 加权联合最小二乘；实现中正确保存峰值、RMS、相位的定义。保留原矩形窗值供诊断与历史可比，不允许把低信噪比成分默默删掉。
- 先用纯已知 1–7×恒幅信号核对幅值和相位，再用“弱 1× + 强非整数阶”复合恒幅信号核对四个子窗；在同一原生机械波形上报告修复前/后子窗估计差异。纯已知同频组合应能恢复已知系数；复合信号的稳定 1×不应仅因窗口变化被误报为机械非稳态。
- **仅修正测量偏差，不修改机械波形。** 同一原生数组的 `E_dir`、10–900 Hz RMS、接触力/脱开统计应前后相同（浮点舍入误差除外）；否则说明修改触及了物理或预处理，需要另行解释。
- 对接近数值底限、泄漏不确定度大于自身幅值的阶次，标记 `ORDER_UNRELIABLE`，单列产生原因与不确定度；不能视为“幅值稳定”的证明。如果所需验收特征仍无法可靠估计，则本工况保留 `INCONCLUSIVE` 而非强制 PASS；扫描不得越过该工况。
- 若更换生产特征定义，版本化记录 `observation_version`，同时保留“历史判据”和“新可靠判据”的结果；不得悄悄覆盖历史数值或放宽门槛。

### 2.3 排查尚未确认的原始机械响应问题

在**固定物理参数和完全相同的初始完整状态/绝对相位**下逐项对照：

1. **积分精度**：DOP853 原步长 `h`、`h/2`、必要时 `h/4` 与更严 `rtol/atol`；用相同物理时长和区间比较原生位移、速度、带内 RMS、M–P 回转指标与接触统计。可用 Radau 交叉核验，但不得把不同初态或不同记录长度的轨迹逐点差误当成纯数值误差。
2. **周向接触离散**：前后四只配合从 `N=512` 到 `N=1024`，仅改变方向离散，保持等效刚度/阻尼解释不变；同时核查各外圈接触开启次数、几何完全脱开率、法向力与能量/耗散。
3. **暂态/分支**：分开检查固定3.5 s热身是否足够，以及480转记录的四个120转子窗是否统计一致。若原生数据不稳，允许在**诊断工况**延长热身或记录到960转，保留原窗口与后窗口并标明是否趋于稳态；不可只截去不合格片段直到通过。
4. **接触模型**：检查单边阻尼和正部律接触开启时的力跃变、力的方向及数值上是否有非物理能量输入。如需修改本构，应单独留存“旧本构/新本构”控制变量对照、方程依据与物理参数来源，不能以“变平滑”为唯一理由。
5. **后轴承阻尼**：把当前 `cb_total=0` 列为模型假设。若证据表明实际导致无物理耗散的数值问题，可提出具备来源和约束的方案，但不得偷偷将其改为正值。所有物理参数变更必须单列，并重新验证等效模型，而不能叫作“只修了算法”。

**先修证据确凿的代码/判定问题；若3.25 μm类波动在原始力学中仍然存在，应归类为“物理非周期/长暂态/多分支或数值未收敛”，在不能证明可信前不判通过。**

### 3.2 稳定性判断：分层门控，不用一个 NOT_STEADY 掩盖问题

每级应至少保存下述独立状态及证据：

| 层级/字段 | 合格条件 | 不合格分类 |
|---|---|---|
| `solver_success` | 积分器正常完成；步长/警告/终止情况可追溯 | `FAIL_SOLVER` |
| `finite_and_bounded` | 所有必需原生状态、加速度、接触力均有限；未越过现有小角度及本构适用域；无不可解释的持续漂移/爆幅 | `FAIL_DOMAIN_OR_DIVERGENCE` |
| `stationarity_physical` | 四等长子窗、六对比较中，M–P回转特征、三通道带 RMS、接触统计等原生物理量通过原门槛 | `FAIL_PHYSICAL_NONSTATIONARY` |
| `coherent_estimator_quality` | 经解析反例校准的阶次估计可靠，明确标注弱分量不确定度；不把泄漏误判为动力学非稳态 | `FAIL_OR_INCONCLUSIVE_OBSERVATION` |
| `numerical_convergence` | 同一级 h/2 与 N加密下关键物理特征满足既定误差限；能明确复算同工况 | `FAIL_NUMERICAL` |
| `input_integrity` | 四只实际间隙、模型DOF、冻结物理配置和源码指纹完全符合合同 | `FAIL_CONFIGURATION` |

原项目的门槛**不得为使更多点通过而放宽**：`E_dir/Ex/Ey`和10–900 Hz三通道带 RMS 的四子窗两两差异不超过 **2%**（对应绝对底限各 `1e-4 μm`、`1e-4 mm/s`）；可靠阶次、残差和动态接触力/峰力比较通常为 **5%**（底限 `1e-4` 对应单位）；接触力冲量 **2%**；几何完全脱开比例绝对差 **≤0.02**；M–P静态中心漂移遵循现有 `stationarity()`。数值 h/N 验收按项目既有 `compare_features()` 同口径执行。

说明：非整数阶谱线、准周期或非单调曲线**不是自动的求解器失败**；是否可称“统计稳态”须由原始 RMS、接触力、位移及数值加密证据决定。若模型确实存在可靠的有界非周期响应，要如实报告这种物理情形；**本轮仍按用户要求将不能满足预先冻结的验收条件的等级标为非通过并停止**，而不是消除它。

## 4. 验收测试与停止条件

### A. 修复前必须保留的证据

- 原始代码的 `fit_joint()` 和 `stationarity()` 对固定恒幅、强异频干扰信号产生误判的重现结果；保留完整的人工输入、旧窗口输出和脚本。
- 参考模型核对：20 DOF/40状态、四外圈独立XY、M–P、 `[4,5,19]`、反力与质量分账、Python/Numba一致性。未发现新硬错误就不要假装修了这些动力学方程。

### B. 修复后的单元验收

1. **观测正确性**：纯1–7×正弦幅值和相位恢复准确；恒幅弱1×叠加强异频后四子窗估计应在预先定义的不确定度内一致。不能用删掉1×/6×或改宽5%门槛来通过。
2. **物理不变性**：纯观测代码修改前后，对同一 `native.npz` 的原始 `q/v`、原生接触力、M–P原始位移和滤波后带内 RMS 不得改变；修复影响仅限被声明的观测指标/验收逻辑。
3. **机械一致性**：后滚动/配合反力无重复加力；Python/Numba在相同随机状态和相同配置下等效；积分保持绝对时间/相位；无无意改变的激励、预紧或安装参数。
4. **控制正确性**：故意令测试组 `steady_pass=False`/抛出求解异常，确认下一组**完全未被调用或创建**，扫描非零退出并保存 `first_failure.json`；故意省略后间隙，确认启动检查能拦截潜在四轴承联动。

### C. 正式扫描的单组通过条件

- 输入完整性与模型结构通过；
- 积分成功、结果有限且模型域合格；
- 预先冻结的原始物理统计稳态要求通过；阶次泄漏问题已经修复，无法解释的特征不确定性不得假装通过；
- 数值步长及接触离散加密满足冻结的比较限，或明确状态 `PENDING` 并按本次认证合同停止；
- 原生完整数据、逐圈回转指标、三通道振动速度、四只轴承的配合接触力与接触占比及运行日志可复查。

**最终总验收只允许以下互斥结论：**

- `ALL_25_PASS`：按合同顺序25级全部通过，且明确列出已完成数值认证范围；
- `STOPPED_AT_FIRST_FAILURE`：首次非通过立即停止，其后等级严格未执行；
- `PRECHECK_FAILED`：修复回归测试或配置入口验收失败，主扫描没有开始。

不得将“全部ODE正常结束”“没有NaN”“合成信号可画图”冒充稳定性验收通过。
