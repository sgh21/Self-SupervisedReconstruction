# 每通道共享 β 实验报告｜2026-10-28

## 本次定义

每个通道的 1×～7× 各阶实测 RMS 幅值，先在各 run 内对父片段取中位数，再在 10 个健康 fit run 间取中位数；这七个幅值的均方根除以精确四隙 1 μm 仿真的七阶幅值均方根，得到该通道唯一 β。三个通道分开计算，均使用实测除以仿真。验证和测试背景未参与拟合。

| 通道 | 实测七阶幅值均方根 mm/s | 1 μm 仿真七阶幅值均方根 mm/s | 共享 β |
|---|---:|---:|---:|
| ACC2_Hx | 0.00953794782 | 0.0133516489 | 0.714364789 |
| ACC1_Hy | 0.008446028 | 0.0129051477 | 0.654469689 |
| ACC3_Py | 0.0212833768 | 0.0156691631 | 1.35829697 |

沿用之前的合成机制：对各阶仿真幅值取当前间隙减 1 μm 的有符号差，乘对应通道 β 后叠加至同一健康背景的对应阶次，保留背景拟合相位及剩余信号；目标振幅为负时裁至零。1 μm 差值为零。3 通道×7 阶全部参与，不使用旧 β 的三项禁用掩码，也不对融合 RMS 或其他旧门槛做验收。

注意：上一轮是逐阶 β 且启用 18/21 项，本轮是每通道共享 β 且启用全部 21 项，因此下方比较同时改变了 β 规则和参与阶次，不能归因于单一因素。

## TCN 结果

复用已保存的 20 级仿真、同一个健康背景和冻结 TCN 权重，无新动力学积分、无训练。20 条波形、80 个 1 s 窗口全部完成推理。沿用用户此前画图要求，只从曲线中去掉 4.210526 μm，20 组数组与指标均保留。健康分母为同一个精确 1 μm 零注入对照的 MSE `9.324875804850308e-7 (mm/s)²`。余弦是不去均值的每窗每通道余弦，再对通道和窗口等权平均。

在展示的19组中，本轮有 14 组的 MSE 低于逐阶 β，13 组的余弦相似度高于逐阶 β；这只是该模型与单一背景上的重建结果。曲线不是单调递增，不能直接解释为物理真实性或实机精度。
