## 4. 搜索中的联合评价

### 4.1 健康RMS误差

使用β之前的10–900 Hz速度RMS，通道为ACC2/Hx、ACC1/Hy、ACC3/Py。健康参考沿用既有健康拟合组，按父片段→run中位数→拟合组中位数聚合，不引入测试背景选参。

对每个通道，令r_c=仿真1 μm RMS/健康参考RMS，健康目标为：

`H = mean_c(log(r_c)^2)`。

H越小越好，同时保存每通道比值和百分比差。已有[0.5,2]比值范围仅作为既有宽范围检查，不能把“落入范围”当作已精确对齐。留出健康验证组用于冻结后的复核，不根据测试集或TCN曲线反向调参。

### 4.2 四个指定点的分窗稳定性

每个候选分别生成3.5、4、4.5、5 μm信号，各自独立冷启动。正式口径沿用热身3.5秒、保留480转，分成4个120转窗口；逐通道取Hann功率谱10–900 Hz积分后开方的RMS。

四窗共6对比较。a、b为同通道两个窗口RMS：

- 曲线显示的相对差：`D = 100×|a−b|/max(|a|,|b|)`，两者均为0时记0。
- 原有验收准则：`|a−b| ≤ max(1e−4 mm/s, 0.05×max(|a|,|b|))`。
- 目标中的归一化违例：`z = |a−b|/max(1e−4, 0.05×max(|a|,|b|))`，`e=max(z−1,0)`。

绝对底限和5%相对门限都保持原样；报告纯相对差与实际通过状态，不能临时改变低幅值规则。稳定性目标使用：

`S = max(e)^2 + mean(e^2)`，统计全部4工况×6窗对×3通道。

最坏违例参与目标，避免仅靠平均值掩盖某个严重超差工况。四个指定点都必须独立列出逐通道最大差、通过状态和最坏比较位置。

### 4.3 候选评分与选取

联合目标建议固定为`J=H+S`；权重在执行合同中预先登记，不因中途结果不好而更改。每个有效候选都完成1+4个工况，才计算完整评分，不允许只因健康RMS好就跳过其稳定性计算。

候选选择顺序：

1. 积分成功、有限且满足模型适用域是基本有效条件；缺失波形或指标不能填0装成稳定。
2. 若存在三通道健康比值均在既有范围内、且四个指定点RMS全部通过的候选，从中选H最小者，同时报告S和最坏窗口差。
3. 若没有共同满足条件者，在有效候选中选J最小者，保留H、S、健康超差与稳态超差清单；不能只给一个总分隐藏折中。
4. 同分时优先最坏违例更小、相对起点改动更小者。候选排名包含原始起点，优化后不能无解释地选一个更差方案。

回转误差、1×、接触力、非整数带等仍保存和报告，但不另外加入本轮优化目标。RMS通过不能自动写成全部物理指标通过。

使用最终K/C下精确四隙1 μm的健康仿真重新计算β。旧K/C的β不能直接沿用；旧健康仿真也不能冒充新参数结果。

融合顺序为：**最终参数冻结→新β拟合与冻结→留出质量检查→合成20条退化波形**。沿用既有1–7×有符号幅值差编辑、实测相位及残差保留、负目标幅值裁零，不逐窗缩放，也不为了使曲线单调而调β。仅使用一组固定健康背景，并保存run/parent来源。

精确1 μm健康参考的合成应为零增量，与健康父信号逐位一致。它是额外健康对照，不把网格里的1.052632 μm标成1 μm。健康对照与20组正式退化数据分开登记。

分别保存来源仿真物理/RMS状态与合成波形RMS状态。即使源信号稳定，融合后的健康背景波动仍可能使合成RMS检查未通过，不能混淆两种结论。β逐分量验证失败、禁用项、裁零项和未知不确定度都应保留。
