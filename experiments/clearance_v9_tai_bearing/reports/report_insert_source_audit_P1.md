# V9报告插入稿：来源核对与P1局部求解器

## 来源核对与物理条件

已对计划 F01–F19 的关键原文页作渲染核读，逐项证据见[来源审计](../source_audit.md)及`references/source_audit.csv`。Tai–Altintas Part I 式(4)的球平衡中陀螺项符号与 F08 一致；Cao–Altintas 2004 式(40)–(41)给出的内、外圈局部力和力矩与 F12 一致。Cao 原式是作用于套圈的 wrench，转成整机方程左端恢复量时仍须由虚功和正位移单元测试确定整体符号；不应另加旧 V8 压力中心矩。由于接触系数随角度变化且含球惯性，不能把完整凝聚 wrench 宣称为已证明的保守势梯度。Tai 式(5)外圈接触角分母印作 `fi`，但同文式(8)与 Cao 式(30)、(32)支持 `fo`，本实现按交叉证据更正并保留原文笔误记录。

NASA TM-81691 的赫兹椭圆拟合表覆盖名义曲率比附近若干离散点，支持名义工况使用近似；它没有给出通用硬边界。圆接触极限和拟合适用范围应单独核验，超出已核区间用椭圆积分，不以常数裁剪代替。GMN 资料只支持通用室温材料参数；`fi=fo=0.54` 是借用先验，GMN 未确认这两个轴承特殊后缀的实际滚道曲率。90/70 N 是当前合同中**每只轴承**的静止轴向参考载荷，不代表已查明的 DB 总预紧机构。模型采用固定位置预紧：由参考载荷反求 `a_pre`，扫描时固定该位置并记录轴向约束反力，不在运行中强制恒力。实际装配、热态预紧、外圈柔度、摩擦牵引和本机接触状态仍未知。12DOF 与 DB/DB 布置是本项目的建模合同和结构假设，不是 Tai/Cao 原模型的严格降阶。控环按候选分支及自洽条件判定；TXM 保持架外圈引导不能单独证明滚动体由外圈控制。内圈失接触分支有原文依据，不能外推为外圈脱离或自由保持架动力学。

## P1阶段证据与结论边界

P1 的独立单轴承代数求解器完成赫兹几何/材料、双接触平衡、内圈失接触、两侧套圈 wrench、局部残差和方向/接触切换等检查。当前验证记录为 281/281 项通过、无条件项或失败项；独立随机求根检查前后轴承各 2500 个状态均无求解失败，最大力平衡残差分别约 `9.99e−9 N` 和 `9.93e−9 N`。随机几何偏置用于数值鲁棒性检查，不代表真实运行范围。12DOF 接入力检查和短积分也通过（2 转）；这证明所测接口与短时数值路径可用，不等于长时间稳态、完整间隙扫描或实机预测已经通过。A 组长时运行及其分支/稳态验收应以最终运行证据另行报告。

上述是局部方程与数值实现验收，不是轴承本机参数或整机动态准确度验证。V9 的名义几何、预紧和控环属于条件模型；结果只能在明确列出的材料、曲率、预紧、相位、阻尼与外圈约束假设下解释。完整逐式来源、已知近似及未决项见[来源审计](../source_audit.md)。
