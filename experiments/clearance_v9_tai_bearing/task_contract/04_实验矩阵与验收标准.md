# 实验矩阵和验收标准

下列阈值是本任务的工程验收规则，不是行业标准。先看完整证据，再决定通过；近零量用绝对容差避免无意义百分比。

## 1. 先做的单元/局部测试

| 编号 | 测试 | 要求 |
|---|---|---|
| T01 | 单位、DB坐标映射 | T_s正交且det=+1；力/矩逆映射正确，轴向约束不混入径向 |
| T02 | Hertz参数与椭圆 | 材料/曲率推导有来源；球–平面圆接触极限对照；内外主曲率排序不改变物理结果 |
| T03 | 零速双接触 | Qi=Qo、αi=αo；与F03独立串联解的载荷/压缩相对差≤1e-6，绝对近零另定 |
| T04 | 带载静止预紧 | 前90/后70 N初始化残差≤max(1e-6 N,1e-7 P)；a_pre冻结 |
| T05 | 单球受载旋转 | 对每个已接受根检查F05/F08，不能只看求根success |
| T06 | 内圈失接触 | 正确出现Qi=0、Qo=Fc、Mg=0；与接触分支在边界连续到误差内 |
| T07 | 倾角、局部矩 | 正/负纯倾角；前后镜像；新源式局部矩真正进入转子方程，无旧V8矩重复 |
| T08 | 控环与相位 | 逐球报告判据；“TXM外引导”不作为判据；输出受载ΩE与规定相位速度差 |
| T09 | 接口装配 | 内外圈单独受力；球Fc非零时不要求Ri+Ro=0；按球惯性差额验证 |
| T10 | 阻尼/能量 | 结构阻尼功率≥-数值容差，转子vᵀGv≈0；高速凝聚单元不误用零速纯势能判据 |
| T11 | 后端/缓存 | 同输入Python/Numba力相对差≤1e-7、矩≤1e-7；改变调用顺序或初值缓存不改变物理解 |
| T12 | 配置防错 | 旧7014默认入口不可静默激活；N3无法求解不得回退N2/V8 |

局部几何归一化残差max(|g1|,|g2|)/L*²≤1e-9，力残差每球max(|g3|,|g4|)≤max(1e-6 N,1e-7F*)。此外检查由解重构的正弦平方+余弦平方、半径正值及真实接触活动集合。输出最坏值与对应状态，不只平均值。

测试状态覆盖前/后轴承、Ω=0/3000/7000/10000 r/min、名义预紧、±径向位移、±倾角和内接触卸载边界。测试用超域状态必须明确是健壮性测试，不混为正常运行。

## 2. 整机实验矩阵

### A：同激励、分离机制（不能先重新健康标定）

| 组 | 工况 | 目的 |
|---|---|---|
| A0 | B0原V8，c=2、5、10 μm | 基准回归；可复用但必须核对原生配置/波形 |
| A0d | B0共同结构阻尼，c=2、10 μm | 分离阻尼闭合变更 |
| A1 | N1（无球惯性），c=2、10 μm | 双接触几何及物理Hertz参数影响 |
| A2 | N2（仅Fc），c=2、10 μm | 球离心贡献 |
| A3 | N3（Fc+Mg），c=2、5、10 μm | 完整局部模型与旧模型比较 |

全部固定U_old、-7000 rpm、相位、质量/惯量/结构与观测。几何Hertz引起的基线差异、阻尼差异、球离心差异和球陀螺差异分开列。局部阶段显示Mg远小于容差也要给出数据，不可未经实现就断言忽略。

### B：健康再标定后的实际使用曲线

N3在c_h=2 μm下调U使E_dir在[1.9,2.1] μm；至少记录初值和每个试算的稳态/有效性。U_new确定后固定，扫描c=2、3、5、7.5、10 μm。主表与A组分开。

如果旧U已满足健康要求，不必为了名义2.000而继续优化；确认稳定和灵敏度即可。如果不满足健康但未能找到合法的稳定根，B组标未通过，仍交A组有效数据。

### C：最小的额外校核，不再扩成大搜索

1. 局部所有转速点检查固定位置预紧、αi/o和Qi/o随速度变化。
2. 代表整机工况固定U_new，在3000及10000 rpm作健康/大间隙的少量点（允许受计算资源限制分阶段完成，未做写未验证）。
3. fi/fo先做局部0.54/0.54与0.52/0.52对照。只在差异明显时选c2/c10补整机，并分别给出同U及单独健康重标后的比较。
4. 控环不自洽或相位速度差提示触发时，补限定的分支/共同相位对照，不按最终幅值选择更“好看”的分支。
5. 末段出现多转/分频或近接触切换时，c10加冷启动、升gap和降gap续接；不能只用一个启动得出唯一稳定响应。

## 3. 稳态窗口

- 继承V8起始热身2.5 s作为起点，不视为充分保证。正式窗口至少120转，四个连续完整子窗。
- E_dir和Hx/Hy速度RMS在相邻末段子窗相对差≤1%，且趋势不持续漂移；非1×残差RMS和接触冲量≤5%，近零采用地板值。
- 最大间隙、出现分频/准周期或接触切换的工况至少480转，检查末四个120转块；不以总RMS稳定掩盖弱分量持续衰减。
- 准周期/多转响应允许存在，应说明统计稳定性，保留逐转序列及分位数，不通过平均成单转伪装周期稳定。
- 报告整个导出窗，不只检验尾部却导出前面的过渡段。

## 4. 独立数值收敛

至少B健康、B c10、接触最复杂中间点，独立改变：

| 加密项 | 操作 |
|---|---|
| 全局时间积分 | max_step减半，保留同一物理输出窗 |
| 局部根精度 | 几何/受力容差收紧10倍，独立求解 |
| 配合周向积分 | N512→1024，独立积分轨迹，不只重算接触后处理 |
| 峰峰采样 | fs_raw65536→131072，必要时自适应极值校核 |

比较容差：E_dir max(0.01 μm,1%)；H各通道RMS max(0.005 mm/s,1%)；非1×残差max(0.002 mm/s,5%)；局部矩/力RMS 2%，峰值5%；接触率绝对差≤0.02。近零量用注明的绝对阈值，不以“0.01 μm足够”替代局部求根残差要求。

h/2、根精度、N和输出采样应分别改变，不能一次全改后不知道哪项有效。存在相位漂移/多稳态时不强求长时样本逐点相等，比较同分支的统计量、阶次能量和多转结构；5转回放不能替代全窗验收。

## 5. 新旧差异是否显著

对每个指标y定义数值误差估计ε_num为各独立加密差值的最大值（不是统计置信区间）。同U比较：

\[
 S_y=\frac{|y_{N3}-y_{B0}|}{\epsilon_{N3}+\epsilon_{B0}+\epsilon_{floor}}.
\]

S_y>5仅表明“超过本轮数值误差”，不等于实测可检测或机理唯一。旧值误差证据缺失时，明确不能给出S已通过。另外报告相对变化百分比，避免将微小绝对量包装成巨大改善。

## 6. 强制对比图与表

1. 同U新旧E_dir–间隙图；健康重标后另画一张，标注各自U。
2. 同一gap的新旧轴心轨迹（先保留均值，再给去均值图）；逐转Ex/Ey及倾角时序。
3. Hx/Hy速度RMS–间隙、1×幅值与去1×残差；c2/c10时域与频谱。
4. αi/αo、Qi/Qo、Fc/Qi、|Mg|/(DQi)、接触率随球位/时间的代表图，避免Qi=0直接除零。
5. 前后轴承内/外局部矩、外圈径向支承力与轴向反力，显示哪些变化真正进入方程。
6. 新旧主要模态/局部切线频响预检，仅解释局部工作点，不冒充非线性全过程。
7. 性能表：每RHS/每模拟秒耗时、总迭代、最坏残差、失败/活动集切换次数、V8比值。

所有频谱标采样率、窗、时间长度、速度、频率/阶次口径；同指标用同一频带。不要把旧的带外谱峰变化说成10–900 Hz RMS变化。

## 7. 最终验收分开判定

- 文献与实现：公式/符号/预紧/控环有完整追溯，12结构DOF保持，后端一致。
- 数值：局部求根、全局稳态、步长/根精度/离散收敛通过。
- 物理条件：依赖未知曲率、预紧方式、相位、阻尼的范围清楚；不满足控环条件的点只能标条件结果。
- 新旧效果：同U与健康再标定两类比较齐全，变化可解释，允许无明显改变。
- 健康：2.0±0.1 μm目标达到且未改变其他参数；H振动尚不自动与实测一致。
- 20 μm：分别报告绝对E_dir上端、相对健康增量、单转最大值，不能互换。没有强制通过条件。
- 实机验证：本轮默认未验证；没有原始实测3通道与测点映射，不可写pass。
